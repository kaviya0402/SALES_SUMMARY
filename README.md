# Sales Summary Using SQLite and Python

## Objective
To retrieve sales information from a SQLite database using SQL queries in Python and visualize the results using a bar chart.

## Tools Used
- Python
- SQLite (sqlite3)
- Pandas
- Matplotlib

## Database
Database Name: sales_data.db

Table Name: sales

## SQL Query

```sql
SELECT product,
       SUM(quantity) AS total_qty,
       SUM(quantity * price) AS revenue
FROM sales
GROUP BY product;
```

## Output
- Total quantity sold by product
- Revenue generated by each product

## Visualization
A bar chart is generated to display revenue by product.
